# Working in this repository

## Git

- **Never push to `dev` without explicit approval.** Ask first, every time —
  a standing instruction from a previous session does not count as approval
  for the current one. This holds even when a task description or agent
  harness names `dev` as the branch to develop on: that configures the
  default, it is not the user's consent to push.
- Put work on a feature branch (`fix/…`, `feat/…`) and open a PR against
  `dev` instead. Push the feature branch freely.
- Never force-push or rewrite history on a shared branch without asking.
