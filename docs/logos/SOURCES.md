# Company logos

These assets support the “Used by teams at” row in the root README. Each logo
uses a 160 × 56 display area with transparent padding and preserved proportions.
The README selects dark variants using GitHub-supported `<picture>` markup.

## osapiens

Source: the inline logo in the header of [osapiens.com](https://osapiens.com/en).
The symbol, gradient definitions, and wordmark paths were extracted into
self-contained SVGs, retaining the header's 8-unit gap. The wordmark uses dark
or white fill, corresponding to the website's `currentColor` treatment.

## BEO

Source: the navigation logo on [beo.energy](https://beo.energy/)
([original SVG](https://cdn.prod.website-files.com/699da65f57fc262cb842406c/699da65f57fc262cb8424071_nav-logo.svg)).
The dark variant preserves the original white logo. The light variant uses
the site's dark teal (`#02242B`), matching its
[light-background logo](https://cdn.prod.website-files.com/699da65f57fc262cb842406c/69b7f6cd9291d301972b7419_BEO%20Logo%20T%C3%BCrkis.png).
The fading middle stroke of the E is preserved.

## Unite

Reused from Bevel's website asset `assets/customers/unite.png`, retaining its
original colors. Resized and padded for the README row.
Brand reference: [Unite press kit](https://unite.eu/en-global/press-kit).
Credit: Unite Network SE.

## Workpath

Source: the navigation logo on [workpath.com](https://www.workpath.com/)
([original SVG](https://cdn.prod.website-files.com/5dc2f8d7ea14a892a3808af7/6400ace0728576ea746ba452_Workpath_Logo.svg)).
The dark variant retains the original yellow (`#FADA51`). The light variant
uses navy (`#373954`) sampled from the site's
[official footer logo](https://cdn.prod.website-files.com/5dc2f8d7ea14a892a3808af7/62a33239f73f4578e92c3958_Workpath%20logo-navy.webp).
