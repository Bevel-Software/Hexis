Back links go where the item lives. A skill or tool page's back link now
points at the item's own group page (or the personal page for personal
items) instead of the Library root, which became the all-groups index and
stopped being where anyone came from. The connect-your-tools page, which
had no way back at all, gets one to Skills & tools.
