A `SKILL.md` written outside `Plugins/` is refused with the path that would work, instead of committing successfully and producing no skill. A skill is found by where it sits — the catalog scanner, the pending-skill shelf and the plugin pages all read `Plugins/` and nothing else — but `SKILL.md` appeared only in that read-side code, so a write anywhere else passed every gate, committed, pushed and reported success while the product ignored it. There was no warning when such a change request was proposed, none when it merged, and no trace in the Library: the file was real and the skill did not exist. A change request adding `Skills/example/SKILL.md` — correct when it was written, then left behind by the `Skills/` → `Groups/` → `Plugins/` migrations — would still merge cleanly today and change nothing. Every path that creates a file now checks placement: the agent's file tools through the lock-aware filesystem's `validateWrite` hook (alongside the `roles.yaml` guard it already carried), `copy_file` and `move_file` through a path-only hook on the same filesystem, the editor's file-save and upload routes, and — per extracted entry — both unzip callers. Placement reads the path and not the bytes, so a binary upload is judged exactly like a text save. An archive is judged entry by entry inside the extraction guard, so a misplaced `SKILL.md` is skipped with a reason while the rest of the archive still lands. A recursive copy judges every file it would create, not just its destination string. Gating `move_file`'s DESTINATION strands nothing — a rescue's destination is a valid place by definition — while refusing the opposite move, which used to take a live skill out of the catalog silently. The rule is the catalog's own and now has one definition, `isSkillDocPath`, which the pending-skill shelf and the write gate share: `Plugins/<plugin>/<skill>/SKILL.md` or deeper. A `SKILL.md` directly in a plugin folder is refused, because the scanner stops descending at the first folder holding one — `Plugins/GTM/SKILL.md` would make that folder the skill and hide every real skill beneath it.
