On a deployment that advertises agent instructions, a connection key revoked while the local server holds it stops the server at the next request. Before every `tools/list` and every tool call, local-only tools and the meta-tools included, the local server asks the deployment whether the key is still live (one read of `/api/agent/instructions`). A refusal answers that request with the deployment's own sentence ("Invalid or revoked connection key. Mint a new one in External agent access." for a revoked key, or, for a key whose account an admin switched off, the sentence telling the person to ask that admin), runs nothing and sends no vault variable, then the server shuts down and the `hexis-mcp` command exits non-zero. A local tool used to keep running for up to five minutes on its cached variables, and forever when it had none. A deployment that cannot be reached, does not answer within three seconds (a sign-in renewal included), or answers 5xx is not a revocation: the request goes ahead as before. In browser sign-in mode, a request the deployment refuses even after renewing the sign-in runs nothing and answers that the sign-in was rejected and the person should restart hexis-mcp and sign in again. An older deployment that does not advertise agent instructions is not asked.
