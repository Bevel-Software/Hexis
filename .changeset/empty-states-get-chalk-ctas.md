Empty states become doorways, in chalk — for the administrator whose call it
is. An empty group's Skills band now says the fact and hands an admin a button
that opens the same add dialog as the title row's `+`, while a hand-drawn
chalk arrow points up at that `+` — drawn as actual chalk (noise-bent
strokes, frayed edges, dry skips), not a smooth vector. The groups index and
the nav spell out the first group the same way, but only while the workspace
holds no groups at all: locked groups mean someone already created one, so
the doorway stands down.

Everyone else reads the same fact with the agent named as their door, exactly
as before — and the `+` itself is untouched for every caller. What is
admin-only is the teaching mark, not the affordance.
