Empty states become doorways, in chalk. An empty group's Skills band now
says the fact and hands over a link that opens the same add dialog as the
title row's `+`, while a hand-drawn chalk arrow points up at that `+` —
drawn as actual chalk (noise-bent strokes, frayed edges, dry skips), not
a smooth vector. The groups index grows the same CTA when the caller is
in no group, and the nav spells out "Create a group" with its own arrow —
but only while the workspace holds no groups at all: locked groups mean
someone already created one, so the doorway stands down.
