"Write your first page" in the Get set up list can ask your agent to write it.

Once an agent is connected, the step leads with "Ask Claude to write it", which opens a new Claude chat in another tab with the request already typed: a page in Knowledge about the company, asking you for anything it cannot find, then saving it. New page stays beside it. Smaller links open the same prompt in ChatGPT or copy it for any other agent. When the page lands in the tree, the step ticks itself as before. Until an agent is connected, the step shows New page and says that a connected agent can write pages for you.
