The plugin marketplace compiled for a person carries only the plugin and skill files that person may read. A plugin whose manifest they may not read (its `plugin.json`, or a bundle's `plugin.bundle.json`) is left out entirely: its folder, its compiled manifests, its MCP servers and its catalogue entries. The skills it links are not withheld with it: one they may read is judged like any other readable skill. Inside a plugin they may read, each file of the folder (a `CONVENTIONS.md`, reference material) ships only when that file is readable, and its MCP servers ship only when the file they come from is readable (its `mcp.json`, or for a bundle the MCP registry its profile expands through). Inside a skill they may read, each of its files ships only when that file is readable. Before, a person with no read on a plugin still received its `CONVENTIONS.md` and its portable MCP servers, and a readable skill was copied with every file in its folder.
