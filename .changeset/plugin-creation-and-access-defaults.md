Agents can make plugins, and the access defaults stop tripping people up.

Two new tools describe the app's own plugin endpoints, so an agent has the same doors a person has: `my_plugin` ensures the caller's private space and returns where its skills go, and `create_plugin` makes a shared plugin, at the root or inside a grouping folder. The endpoints (`POST /api/plugins`, `POST /api/plugins/personal`) now accept a connection key as well as a session; there is one implementation, and the tools are UTCP descriptions of it. In the app, "New plugin" from a folder in the Plugins tree creates the plugin inside that folder rather than at the root; a folder that is a plugin, or sits inside one, does not offer it. Clicking a plugin's own file in that tree — its `access.md`, its manifest — now opens the file, where before it bounced to the plugin page and, for a personal space or a folder spelled unlike its manifest, said the plugin did not exist. The sidebar's group view is labelled "Groups", and the change-request dock — the requests waiting on you — sits under the Skills & Tools nav as it does under the Knowledge tree.

Defaults that used to lock people out: the managed `AGENTS.md` now grants itself `read: everyone`, since every agent is told to read it first and a fresh root grants read to nobody; a plugin's generated `access.md` explains, in each of its two blocks, what that block governs and how to admit people (the top block's `everyone` only makes the plugin discoverable, which read as "everyone does nothing"); and a personal plugin's `access.md` denies `everyone` read outright and names only the owner — not even Admin reads a private space by default — so opening the repository root with `read: everyone` no longer opens every person's private space with it. Personal spaces seeded by an earlier release get the same rule on the first start after the upgrade, on every branch: the denial is added to the folder's read rules, the owner's grants (which the old seed kept in the top block, where they never governed the folder) are carried into the folder's rules, and nothing else in the file moves.
