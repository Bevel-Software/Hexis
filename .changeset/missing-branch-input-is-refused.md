A knowledge-base tool call that names no branch is refused by name instead of being resolved to a branch called `undefined`. A missing, empty or non-string `branch` — and the stringified absent values `"undefined"` and `"null"` a client sends when it interpolates a variable it never set — answers 400 with kind `branch-required` and one sentence naming the input and what to pass. It is refused at the boundary, so no workspace is created and no clone is attempted, and it is refused on the mount every branch-taking tool shares — the workspace tools' and the workflow tools' — as well as at the resolver choke point beneath them (`getFilesystem`), so a call made from inside `call_tool_chain` gets the identical answer. The mount is what makes the claim hold for the whole surface rather than most of it: a tool that never asks for a filesystem (`unzip` hands its branch to the workspace service as an id, `commit_change` as a workspace id) would otherwise slip past the resolver, and a tool added later would have to remember the check on its own. The branch is never defaulted: a tool's workspace is named by its argument, and an omitted argument silently acting on the protected default branch is worse than an error. `execute_command` is the one tool that still resolves an omitted `branch` itself — an internal session's own focused branch, from its signed token, which is a branch the caller named rather than a default — and it now answers the shared `branch-required` kind when there is nothing to fall back on, so a client switches on one discriminator across the whole surface.

A bootstrap that fails to clone now rolls back the workspace directory it created, not just the clone inside it. A directory named after a branch is one of the ways the platform remembers having known one, so the leftovers of a first failed attempt used to turn every later attempt at the same name from "there is no branch named x" (404) into "branch x no longer exists on the remote" (410) — telling the reader a name they had invented once existed and was deleted. A name the platform has never cloned or listed now answers 404 on every attempt.
