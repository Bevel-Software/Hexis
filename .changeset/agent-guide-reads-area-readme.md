The agent guide tells agents to read an area's `README.md` before they create, move or reorganise files there, and to keep it current.

"Where a new file goes" now opens with it: read the `README.md` of the folder and of each folder above it, because a README says how that area is organised (where each kind of file goes, what each subfolder holds). Its layout rules come before the guide's general ones for that area, and never widen access. When an agent adds a subfolder or a new kind of file, or settles a convention, it updates that README in the same change. Two agent sessions had made conflicting structural choices in one person's space because neither read the README that described it.
