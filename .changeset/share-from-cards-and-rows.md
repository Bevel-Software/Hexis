Every skill card and plugin row now carries its own "…" menu — on Everything, on Owned by me, on a group's page, on a plugin's own page and on your own space — so sharing is offered on the thing you are looking at rather than only on the page you have to open first. The button appears on hover and on focus and is a real tab stop after the card; a right-click anywhere on the card or row opens the same menu at the pointer. Opening it moves focus to the first item, the arrow keys (and Home/End) walk the list, and Escape closes it and hands focus back to the button — as do picking an item and tabbing out of the menu, so focus is never left on the item that just went away. Clicking the card or row body still opens the item, exactly as before.

A skill's "Share" opens Manage access on the skill's own folder — the same dialog, on the same folder, as the skill page's Share. On a plugin's page that is the skill's folder and not the plugin's, and it reuses the dialog the title row's Share already opens, so a rule the skill inherits from the plugin is managed by walking up to it from the dialog rather than being read-only there. On a card that also offers Remove, the "…" keeps the corner and Remove steps left of it. A plugin row's Share opens the plugin's primary folder, as the plugin page's does. For a plugin the caller cannot read, the menu offers "Subscribe" in place of Share: the same request, the same toast naming the people who decide, and the same "Requested" afterwards as the locked plugin page's button. Every page's access dialog reads and writes the default branch the catalog itself was read from, whichever branch happens to be open elsewhere.

Tool cards are unchanged and carry no menu — access to a tool is decided at the plugin that carries it, so a tool has no rules of its own to open. The card's props now say so in the type rather than leaving it to a runtime check.
