Skills reach Cowork and claude.ai as native plugins. Those surfaces take marketplaces only from GitHub or from a GitHub Enterprise Server the Claude organization registered, so the platform now answers as one: an admin finds generated registration credentials on the Deployment page and an Owner enters them once in Claude's admin settings (Team or Enterprise plan). From then on each person adds the marketplace URL in Cowork, connects their account through the ordinary sign-in, and receives the marketplace compiled for exactly what they may read. The same URL still serves Claude Code and Codex as a git remote.

External agent access gains a third tab, Marketplaces, holding the Cowork route, the person's Claude connections (disconnectable like any key), and the git-remote commands that used to sit on the Your agent tab. The connect flow reuses the existing sign-in and consent page; the token Claude holds is a connection key.
