Knowledge views now open inside the chat. Every HTML knowledge view a person can read (a page made with the html-knowledge-view skill) becomes a tool of its own on the local hexis-mcp server, `show_<name>`, and an MCP Apps host renders the page in the conversation. A view whose snapshot records how it was built (its mirror) shows live data from the knowledge base; any other view shows the data it was saved with. In an inline or narrow frame the view shows a compact list built from the board's own definition; fullscreen shows the page as written. Links in the page open in the Hexis web app, and the page's "copy changes" sends the changes to the chat as a message, and still copies them. The list of views and each page are kept under `~/.hexis/views`, readable only by their owner, so a restart serves them at once and refreshes in the background. The views sit beside the deployment's own `open_page` view and never share an address with it, and they keep working when the workspace's other tools could not be loaded.
